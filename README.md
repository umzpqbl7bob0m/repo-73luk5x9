# Atlas Arbitrage Scanner

Read-only сканер межбиржевого крипто-арбитража с современным интерфейсом, учетом комиссий и пошаговыми маршрутами исполнения.

![Node.js 20](https://img.shields.io/badge/Node.js-20%2B-38d996)
![Mode](https://img.shields.io/badge/mode-read--only-9b6cff)

## Возможности

- публичные котировки **Binance, OKX, Bybit, Gate.io и KuCoin**;
- DEX-пулы через **DexScreener** для настраиваемых token contract addresses;
- сопоставление одинаковых активов между площадками;
- расчет gross spread и net profit после:
  - taker-комиссии покупки и продажи;
  - slippage на обеих операциях;
  - комиссии вывода в монетах;
  - ориентировочной стоимости сети/газа;
- оценка уверенности сигнала по ликвидности, размеру спреда и типу данных;
- подробный план: где купить, куда перевести, сколько ждать и где продать;
- отдельный what-if калькулятор;
- локальная база комиссий;
- административные настройки источников, капитала, порогов и DEX watchlist;
- demo fallback, если внешние API недоступны.

## Быстрый старт

Требуется Node.js 20 или новее. Внешние npm-зависимости не нужны.

```bash
npm start
```

Откройте `http://localhost:3000`.

Для разработки с автоматическим перезапуском:

```bash
npm run dev
```

## Конфигурация

Основные параметры находятся в [`data/config.json`](data/config.json) и меняются через раздел «Настройки»:

| Параметр | Назначение |
|---|---|
| `capitalUsd` | капитал одной расчетной сделки |
| `minProfitUsd` | минимальный абсолютный порог сигнала |
| `minProfitPercent` | минимальный процентный порог |
| `maxSpreadPercent` | отсекает вероятные совпадения разных токенов с одинаковым тикером |
| `slippagePercent` | slippage на каждую операцию |
| `minLiquidityUsd` | минимальная DEX-ликвидность |
| `scanIntervalSeconds` | период обновления |
| `enabledSources` | активные коннекторы |
| `dexWatchlist` | chain ID, contract address и символ токена |
| `networkCostsUsd` | ориентировочная стоимость сети |

Стартовые тарифы площадок находятся в [`data/fees.json`](data/fees.json). Перед использованием с реальным капиталом обновите комиссии вывода для нужных активов и сетей.

Переменные окружения:

```bash
PORT=3000
HOST=0.0.0.0
```

## API

| Метод | Endpoint | Назначение |
|---|---|---|
| `GET` | `/api/health` | состояние сервиса |
| `GET` | `/api/scan` | последний снимок рынка |
| `GET` | `/api/scan?force=1` | принудительное обновление |
| `GET` | `/api/config` | текущая конфигурация |
| `PUT` | `/api/config` | валидация и сохранение настроек |
| `GET` | `/api/fees` | база комиссий |
| `POST` | `/api/calculate` | независимый расчет сделки |

## Как трактовать сигнал

1. Убедитесь, что обе площадки принимают один и тот же токен, а не одноименный актив с другим контрактом.
2. Проверьте, что депозит и вывод работают в одной сети.
3. Сравните доступную глубину стакана с расчетным размером сделки.
4. Пересчитайте актуальные VIP/tier комиссии и стоимость вывода.
5. Учтите время подтверждения, memo/tag, bridge fee и изменение курса.
6. Только после повторного сканирования принимайте самостоятельное решение.

## Ограничения и безопасность

- Приложение **не совершает сделки**, не подключает кошельки и не хранит API/private keys.
- Публичные API могут быть недоступны из-за rate limit, обслуживания или региональных ограничений.
- Stablecoins в расчетах принимаются приблизительно за 1 USD; depeg-риск не моделируется.
- DEX bid/ask аппроксимируются вокруг `priceUsd`; точный quote зависит от размера сделки, маршрутизатора и MEV.
- Комиссии и интервалы являются справочными, а не гарантированными.
- «Все биржи и все токены» невозможно гарантировать из одного приложения: новые коннекторы добавляются в `src/connectors/index.mjs`.

Это аналитический инструмент, а не финансовая рекомендация и не гарантия прибыли.
